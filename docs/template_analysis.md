# Template Analysis – ServiceHub AI

## Comparison of GitHub Project Templates

| Template         | Workflow Columns                  | Automation Features               | Agile Suitability                   |
| ---------------- | --------------------------------- | --------------------------------- | ----------------------------------- |
| Basic Kanban     | To Do, In Progress, Done          | No automation                     | Suitable for small/simple projects  |
| Automated Kanban | To Do, In Progress, Done          | Auto-moves issues based on status | Highly suitable for Agile workflows |
| Bug Triage       | New, Investigating, Fixed         | Focused on issue tracking         | Limited to bug management           |
| Team Planning    | Backlog, Ready, In Progress, Done | Supports planning and tracking    | Suitable for structured Agile teams |

---

## Selected Template: Automated Kanban

The Automated Kanban template was selected for the ServiceHub AI project because it aligns closely with Agile development practices.

This template provides built-in automation that automatically moves issues between columns based on their status. This reduces manual effort and ensures that the board remains up to date as development progresses.

Additionally, the workflow structure (To Do, In Progress, Done) supports iterative development and allows tasks to be tracked efficiently across different stages.

The template also integrates well with GitHub Issues, enabling seamless traceability between user stories, requirements, and implementation tasks.

Overall, the Automated Kanban template supports sprint-based development, improves workflow visibility, and enhances productivity, making it the most suitable choice for this project.
