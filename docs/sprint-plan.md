# Sprint Plan – ServiceHub AI

## Sprint Duration

2 Weeks

## Sprint Goal

Deliver a Minimum Viable Product (MVP) that allows users to register, log in, search for services, and book services.

---

## Selected User Stories for Sprint

* US-001: Register account
* US-002: Login
* US-003: Search services
* US-004: View service details
* US-005: Book service

## Sprint Goal Justification

This sprint focuses on delivering the core functionality required for users to interact with the platform. These features form the foundation of the system and align with the most critical stakeholder needs, particularly usability and service accessibility.
