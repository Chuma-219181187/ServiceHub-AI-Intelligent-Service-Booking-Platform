# Agile User Stories – ServiceHub AI

| Story ID | User Story                                                                           | Acceptance Criteria                                | Priority |
| -------- | ------------------------------------------------------------------------------------ | -------------------------------------------------- | -------- |
| US-001   | As a customer, I want to register an account so that I can access the platform.      | Valid email required; account created successfully | High     |
| US-002   | As a user, I want to log in securely so that I can access my dashboard.              | Valid credentials; token generated                 | High     |
| US-003   | As a customer, I want to search for services so that I can find providers easily.    | Results displayed within 2 seconds                 | High     |
| US-004   | As a customer, I want to view service details so that I can make informed decisions. | Service info displayed clearly                     | High     |
| US-005   | As a customer, I want to book a service so that I can schedule an appointment.       | Booking created with date/time                     | High     |
| US-006   | As a customer, I want to make a payment so that I can confirm my booking.            | Payment processed successfully                     | High     |
| US-007   | As a customer, I want to leave a review so that I can share my experience.           | Rating between 1–5 saved                           | Medium   |
| US-008   | As a provider, I want to manage my services so that I can update my offerings.       | CRUD operations successful                         | High     |
| US-009   | As a provider, I want to manage bookings so that I can accept or reject requests.    | Booking status updated                             | High     |
| US-010   | As an admin, I want to approve providers so that only verified users offer services. | Approval updates provider status                   | High     |
| US-011   | As a system, I want to send notifications so that users are informed of updates.     | Notifications sent after actions                   | Medium   |
| US-012   | As a system, I want to recommend services so that users get personalized results.    | Recommendations based on history                   | Low      |
